# N++ tools

N++ is a fun [game](https://nplusplus.org/).

**attract-watcher:** Server that watches the latest attract files and exposes them through a websocket.
**ntools-rs:** Rust code for handling game related logic. Game simulation is ported from [nclone](https://github.com/SimonV42/nclone).
**nview:** Web frontend ui that uses ntools-rs as webassembly.

Many thanks to the projects [outte++](https://github.com/edelkas/inne) and [nclone](https://github.com/SimonV42/nclone).
